5 · What descent found is what sparse-layout ships

layout-descent decisionsparse-layout equivalent

Starting from the benchmark's naive nested persistent map, two measured moves reach orders [0 1] :csf + [1 0] :csf — exactly :indices #{:csr :csc}, the index set defsparse compiles in the benchmark. The search also confirms the library's default: with 12 entries per row, binary search in a sorted CSR span beats a hash point index, so no third index is justified at this sparsity.
